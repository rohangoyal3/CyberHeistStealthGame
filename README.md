# CyberHeistStealthGame
🎮 Cyber Heist - A Java Swing Stealth Game
Cyber Heist is a 2D stealth-based desktop game built using Java Swing, where you step into the shoes of a hacker infiltrating a high-security facility. Your mission: dodge patrolling guards, outsmart surveillance cameras, and steal sensitive data — all without getting caught!

🕹️ Key Features
Stealth Mechanics: Sneak past enemies and security cameras using strategic movement.

Custom Login System: Secure user authentication with registration, login, and "Forgot Password" functionality.

CSV-based User Management: All user data is stored in a structured CSV file (or MySQL, in some versions).

Interactive UI: Designed with Java Swing for a responsive and intuitive experience.

Expanding Levels (Coming Soon): More complex layouts, advanced AI, and tools for hacking.

🔐 Tech Stack
Java (Swing)

CSV File Storage (alternative version with MySQL)

JavaMail (for OTP in Forgot Password)

🚀 How to Run
Clone the repo

Run the main class (Main.java)

Register or login to begin your stealth mission!
